# Mohamed Hatata — Portfolio

A responsive static portfolio website based on the supplied 8-page Gamma portfolio PDF.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
1. Create a GitHub repository, e.g. `MohamedHatata.github.io`.
2. Upload all files and folders in this project.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will publish the site.
